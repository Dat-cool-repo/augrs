## Albumentations 2.0.8 (MIT)

<https://github.com/albumentations-team/albumentations>, the last MIT-licensed release.

augrs follows Albumentations' public API and behaviour: transform and argument names, defaults and
scalar conventions, bounding-box and keypoint formats and filtering rules, `Compose` / `OneOf` /
`SomeOf` / `Sequential` semantics, parameter-sampling rules (for example `RandomResizedCrop`
windows and `CoarseDropout` holes, which in turn follow torchvision), the `RandomGamma` and
brightness/contrast lookup-table arithmetic, and the `A.to_dict` / `A.save` serialisation format.
The test suite (`compat-tests/`) compares augrs against an installed copy of Albumentations 2.0.8,
and `compat-tests/fixtures/` contains configuration files exported by Albumentations 2.0.8 with
`A.save` (generated by `compat-tests/fixtures/make_albu_fixtures.py`).

## OpenCV (Apache-2.0)

<https://github.com/opencv/opencv>. Copyright the OpenCV authors and contributors. Licensed under
the Apache License, Version 2.0 (a copy is in [LICENSE-APACHE](LICENSE-APACHE)).

Albumentations is built on OpenCV, so matching it means matching OpenCV's arithmetic. The
following augrs kernels are Rust reimplementations that reproduce the corresponding OpenCV
algorithms and their integer/floating-point arithmetic:

- `crates/augrs-core/src/ops/hsv.rs`: 8-bit `COLOR_RGB2HSV` / `COLOR_HSV2RGB` (the 12-bit
  reciprocal-table division, the vectorised HSV-to-RGB formula with its truncation and fused
  multiply-adds, and the rounding scalar loop OpenCV uses for row tails).
- `crates/augrs-core/src/ops/clahe.rs`: `cv::createCLAHE(...).apply` on 8-bit images (tile
  padding, clipped histograms and redistribution, lookup tables and bilinear blending).
- `crates/augrs-core/src/ops/resize.rs`: the fixed-point arithmetic of OpenCV's bilinear 8-bit
  resize (including the vertical pass of `VResizeLinearVec_32s8u`) and `INTER_NEAREST_EXACT`.
- `crates/augrs-core/src/ops/color.rs`: the fixed-point `RGB2GRAY` coefficients.
- `crates/augrs-core/src/ops/blur.rs`: the Gaussian kernel sigma rule of `getGaussianKernel` and
  the bit-exact 8-bit separable blur scheme.
- `crates/augrs-core/src/border.rs`, `crates/augrs-core/src/geometry.rs`: the `BORDER_*`
  extrapolation modes and the conventions of `getRotationMatrix2D` / `getPerspectiveTransform`.
